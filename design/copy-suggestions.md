# Copy Suggestions

Only changes that materially strengthen point of view are included.

## 1) Homepage Opening (first screen)

## Existing problem
Current opening is strong but still close to a classic service-positioning statement.

## Proposed copy
Heading:
Design decision ownership before you automate anything.

Subline:
I help teams map signal, ownership, and proof gates, then build a working prototype in the real workflow.

## Reasoning
Shifts from "AI capability" to the deeper claim: engineering leverage comes from ownership design and execution proof.

## 2) Decision Review Board Intro

## Existing problem
No concise line currently explains what the first-screen board represents.

## Proposed copy
Label:
Live operating thesis

Body:
This is the sequence I use to decide whether a workflow should stay human, become software, or be split with controls.

## Reasoning
Prevents the board from feeling decorative and reinforces authored method.

## 3) Method Section Lead

## Existing problem
Current line reads process-oriented but not sufficiently decisive.

## Proposed copy
Five steps to reach a justified go or no-go decision, not a slide deck.

## Reasoning
Tightens the practical promise and adds edge.

## 4) Work Page Header

## Existing problem
"Proof over claims" is directionally good but generic in isolation.

## Proposed copy
Each project is logged as: pressure -> boundary -> mechanism -> result -> failure modes.

## Reasoning
Names the exact structure and aligns with the ledger identity.

## 5) Counterpoint Section (Where AI Should Stop)

## Existing problem
The stance exists but can be made sharper.

## Proposed copy
If deterministic automation solves it with lower risk, AI is the wrong tool.

## Reasoning
Short, memorable, and credibility-building for technical decision-makers.

## 6) Contact Prompt

## Existing problem
Current contact copy is friendly but does not signal decision rigor strongly enough.

## Proposed copy
Bring one workflow that is slow, expensive, or inconsistent.
You leave with a mapped boundary model and a practical next move.

## Reasoning
Clarifies outcome and attracts better-fit conversations.
